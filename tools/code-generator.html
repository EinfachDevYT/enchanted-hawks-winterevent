3 · Veröffentlichen

Die Startcodes funktionieren erst, wenn die neue Website-Datei auf dem Server liegt. Nach jedem neuen Club wieder erzeugen und hochladen. Bestehende Codes bleiben dabei gültig.

So kommt die Datei auf die Website
  1. Auf GitHub ins Repo enchanted-hawks-winterevent → Ordner docs → Add file → Upload files → die heruntergeladene data.js hineinziehen → Commit changes.
  2. Auf dem Server: sudo /var/www/enchanted-hawks-winterevent/deploy/update.sh
  3. Fertig. Erst danach die Startcodes per DM verschicken.

Sicherung

Alles wird in diesem Browser gespeichert. Speichere zusätzlich eine Sicherung. Die Datei enthält alle Codes und Lösungen und darf niemals ins Repo.
